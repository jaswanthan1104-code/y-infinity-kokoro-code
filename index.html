About Kokoro Code

Kokoro Code is a custom-created symbolic system, made for Project Y∞. It is not a traditional Japanese cipher and not standard Japanese.

The Japanese characters are real. The token combinations, the numbers and their meanings were created by us. Each code shows two things separately: the Original Japanese meaning, only where your book gives one, and the Custom Kokoro Code meaning.

Number rule: a number alone never decides a meaning. The full token (symbol + number) does.

This is a fun codebook, not strong encryption. Anyone with the book can decode your messages.
